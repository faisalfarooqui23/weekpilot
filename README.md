# weekpilot
Super-Productivity plugin that gives you  a one page dashboard to manage your most important tasks.

What changed:

Top action buttons are now compact, single-line, and properly spaced.
Review week, Plan week, Display, and Insights no longer wrap awkwardly.
Behind schedule now uses a true red-tinted background and red border.
Quick · 15 min or less now uses a green-tinted background and green border.
Those colors stay semantically red/green even if Super Productivity’s selected accent color is blue.
Dragging into Quick also gets a green drop state.
Responsive behavior is improved so the buttons wrap cleanly only when the window is actually too narrow.

That should make the hierarchy feel much more intentional:

Red = attention / overdue
Green = quick wins
Neutral = normal planning sections
